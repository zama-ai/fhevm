# FHEVM SDK

{% hint style="warning" %}
The Relayer SDK (`@zama-fhe/relayer-sdk`) has been replaced by [`@fhevm/sdk`](https://www.npmjs.com/package/@fhevm/sdk). The pages in this section are no longer maintained; the SDK documentation now lives next to its source code.
{% endhint %}

`@fhevm/sdk` is the TypeScript SDK for building applications on FHEVM chains: encrypt values client-side, send encrypted inputs to your smart contracts, and decrypt results. It works with both ethers.js v6 and viem, in the browser and in Node.js.

## Where to go next

🟨 Go to the [**`@fhevm/sdk` documentation**](https://github.com/zama-ai/fhevm/blob/main/sdk/js-sdk/docs/README.md) for an overview of the SDK.

🟨 Go to [**Getting started**](https://github.com/zama-ai/fhevm/blob/main/sdk/js-sdk/docs/getting-started.md) to install the SDK and encrypt and decrypt your first value.

🟨 Go to [**Encryption**](https://github.com/zama-ai/fhevm/blob/main/sdk/js-sdk/docs/encryption.md) to create encrypted inputs for your smart contracts.

🟨 Go to [**Decryption**](https://github.com/zama-ai/fhevm/blob/main/sdk/js-sdk/docs/decryption.md) to decrypt private values with a user permit, or read publicly decryptable values.

🟨 Go to [**Migrating from the Relayer SDK**](https://github.com/zama-ai/fhevm/blob/main/sdk/js-sdk/docs/migration.md) to port existing `@zama-fhe/relayer-sdk` code.

🟨 Go to [**Solidity ACL Guide**](https://docs.zama.ai/protocol/solidity-guides/smart-contract/acl) for more detailed instructions about access control.
